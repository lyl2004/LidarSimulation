# 激光雷达复杂天气散射仿真：完整验证与会议论文准备方案

> 文档状态：工作方案初稿  
> 更新日期：2026-09-01  
> 适用项目：`LidarSimulation`  
> 最终目标：基于现有 Mie/T-matrix、偏振传播、分层大气和激光雷达前向模型，形成一篇可复现、有独立证据链支撑的会议论文。

---

## 1. 文档目的

本文档用于统一后续理论计算、软件验证、公开数据获取、实验设计、统计分析和论文撰写工作。核心原则是将“程序能够运行”提升为“物理实现正确、数值结果收敛、与独立求解器一致、与真实观测相符、结论具有不确定度边界”。

本文档同时作为项目执行清单。每项任务完成后，应补充：

- 使用的代码版本和 Git commit/hash；
- 输入配置、随机种子和依赖版本；
- 原始数据来源、下载日期、产品版本和许可证；
- 输出表格、图件、统计指标和异常说明；
- 是否达到预先规定的验收标准。

## 2. 建议的论文定位

### 2.1 推荐主线

建议将论文定位为：

> 面向雾、霾、沙尘和降雨场景的统一偏振激光雷达前向仿真框架，将球形粒子的 Mie 散射、非球形粒子的 T-matrix/IITM 散射、Mueller/Stokes 偏振传播、分层大气衰减和仪器响应连接起来，并通过解析极限、独立求解器以及公开观测数据构成分层验证证据链。

### 2.2 可以主张的贡献

在完成本文验证工作之前，不应提前声明“高精度”或“已被实测验证”。完成后可根据结果选择以下贡献：

1. 建立跨球形与非球形粒子、跨多种天气条件的统一前向计算链路。
2. 给出从单粒子散射、粒径谱积分到距离分辨激光雷达回波的逐层验证方法。
3. 定量分析粒子形状、粒径谱、复折射率、多次散射和仪器噪声对回波及退偏比的影响。
4. 证明仅以能见度或雨率描述复杂天气存在信息不足，并给出粒径谱驱动模型相对经验模型的改进。
5. 在公开地基或卫星观测上评估模型泛化能力，并明确 1550 nm 应用预测的可信区间。

### 2.3 不宜过度主张的内容

- 仅凭数值曲线不能证明模型对真实大气“准确”。
- 使用同一观测事件调参并评估，不能称为独立验证。
- CALIOP、EARLINET 等 Level 2 反演产品不是无误差真值。
- 532/1064 nm 的验证不能自动等价为 1550 nm 的直接实验验证。
- 经验粒径谱经过拟合后接近个别观测点，不等于模型具备普适性。

## 5. V1：解析与物理一致性验证

### 5.1 单位与定义审计

在比较数值之前，先建立项目统一量纲表：

| 量 | 统一符号 | 目标单位 |
|---|---|---|
| 半径/直径 | `r`/`D` | m，输入可保留 um/mm 但必须显式转换 |
| 消光/散射/吸收截面 | `C_ext/C_sca/C_abs` | m² |
| 后向散射微分截面 | `dC_sca/dOmega(pi)` | m² sr⁻¹ |
| 消光系数 | `alpha` | m⁻¹ |
| 体后向散射系数 | `beta` | m⁻¹ sr⁻¹ |
| 粒径谱 | `dN/dlnr` 或 `N(D)` | m⁻³ 或 m⁻³ mm⁻¹，必须注明自变量 |
| 激光雷达比 | `S=alpha/beta` | sr |
| 线性退偏比 | `delta=beta_perp/beta_parallel` | 无量纲 |
| 相函数 | `P(theta)` | 明确采用积分为 1 还是 `4*pi` 的归一化约定 |

重点审计 `beta` 与 `4*pi*beta`、后向散射效率、后向微分截面和雷达截面的定义，避免因文献口径不同造成固定倍数误差。

### 5.2 瑞利极限

定义尺寸参数：

```text
x = 2*pi*n_medium*r/lambda_0
```

在 `x << 1` 时，对非磁性小球验证：

```text
C_sca = (8*pi/3) * k^4 * r^6 * |(m^2-1)/(m^2+2)|^2
```

并验证：

- 固定粒径时 `C_sca` 随波长近似满足 `lambda^-4`；
- 固定波长时 `C_sca` 随半径近似满足 `r^6`；
- 非吸收粒子的 `C_abs` 趋近 0；
- Rayleigh 相函数与角分布一致；
- 球形粒子的单次散射线性退偏比应趋近 0。

建议参数矩阵：

- `x = 1e-4, 3e-4, 1e-3, 3e-3, 1e-2, 3e-2, 0.1`；
- 实折射率 `m = 1.10, 1.33, 1.50`；
- 吸收测试增加小的虚部，并核对项目采用的复折射率符号约定。

建议验收：在最小尺寸参数区域，截面相对误差达到 `1e-3` 量级或更低；对数拟合得到的波长幂指数接近 `-4`、半径幂指数接近 `6`。最终阈值应根据所用求解器精度固定，并在看真实结果前写入测试配置。

### 5.3 能量守恒

对每组粒径、波长和复折射率计算：

```text
C_ext = C_sca + C_abs
```

分别验证：

- 非吸收粒子：`C_ext = C_sca`；
- 吸收粒子：`C_ext >= C_sca >= 0` 且 `C_abs >= 0`；
- 单次散射反照率 `omega0=C_sca/C_ext` 位于 `[0,1]`；
- 数值残差不随粒径或级数截断系统性放大。

定义归一化残差：

```text
epsilon_E = |C_ext-C_sca-C_abs| / max(C_ext, tiny)
```

建议对 Mie 使用较严格阈值，对 T-matrix 根据条件数和截断阶数使用相对宽松阈值；失败样本不得简单删除，必须保留尺寸参数、轴比、折射率、截断阶数和求解器诊断。

### 5.4 光学定理

核对前向散射振幅与消光截面的关系。实现时必须使用求解器自身的振幅和波数定义，避免直接套用不同归一化文献公式。输出：

- 由前向振幅计算的 `C_ext_optical_theorem`；
- 求解器直接输出的 `C_ext_solver`；
- 二者相对差异及随尺寸参数的变化。

### 5.5 相函数和 Mueller 矩阵

验证：

- `M11` 非负；
- 相函数角积分与 `C_sca` 一致；
- 球形随机取向粒子的对称关系满足求解器理论约束；
- `|M12| <= M11` 等基本物理界限；
- 由 Mueller 元素计算的后向退偏比处于物理区间；
- 角度网格在 0°和 180°附近加密后，前向峰和后向量收敛。

### 5.6 Beer-Lambert 和激光雷达方程

对常数消光均匀介质验证：

```text
T2(R) = exp(-2*alpha*R)
P(R) = C * O(R) * beta(R) * T2(R) / R^2
```

测试场景：

1. `alpha=0`、`beta=constant`，验证 `P(R)*R^2` 为常数。
2. `alpha=constant`，验证 `ln(P(R)*R^2)` 对 `R` 的斜率为 `-2*alpha`。
3. 单层阶跃廓线，验证积分光学厚度的分段解析解。
4. 双层大气，验证层边界连续性和累计透过率。
5. 重叠函数设为 1 和非平凡函数，分别验证几何项与重叠项。

## 6. V2：数值收敛与稳定性

### 6.1 粒径积分收敛

对雾、霾、沙尘、雨分别测试粒径节点数，例如：

```text
51, 101, 201, 401, 801, 1601
```

记录 `alpha`、`beta`、SSA、`g`、退偏比和激光雷达比。以最高分辨率或外推值为参考，绘制误差-节点数曲线。雨滴后向散射有强振荡，应单独验证积分策略，不能只看消光收敛。

### 6.2 角度积分收敛

至少比较：

- 均匀角网格；
- 前向/后向自适应加密网格；
- 不同角节点数；
- 直接角积分与求解器截面输出。

验收指标应包含 `C_sca` 归一化误差、`g` 误差、180°后向量误差和退偏比误差。

### 6.3 距离网格收敛

对相同大气场景使用逐级减半的距离步长，比较：

- 双程透过率；
- 回波峰值和层边界位置；
- 积分 AOD；
- 有效探测距离；
- 层顶/层底定位误差。

### 6.4 T-matrix 截断与形状极端条件

扫描：

- 尺寸参数；
- 轴比；
- 复折射率；
- 截断阶数 `nmax`；
- IITM/EBCM 或可用求解器选择。

将失败区域绘制为参数相图，区分“物理结果变化”和“数值不收敛”。论文必须报告有效计算域，不能将求解器失败样本静默替换为默认值。

### 6.5 随机传播/Monte Carlo 收敛

如当前传播链使用随机采样，应测试光子数：

```text
1e3, 3e3, 1e4, 3e4, 1e5, 3e5, 1e6
```

每个光子数使用不少于 10 个独立随机种子，统计均值、标准差和 95% 置信区间。验证标准误差近似按 `N^-1/2` 下降，并在光学薄极限收敛到单散射解析结果。

固定随机种子只能用于复现，不能代替多随机种子的统计误差分析。

### 6.6 可复现性

同一输入至少执行：

- 同进程重复；
- 不同进程重复；
- 清缓存后重复；
- 使用缓存重复；
- 如条件允许，在第二台机器或第二组 CPU/操作系统环境重复。

比较原始数值数组，而不只比较图片。记录允许的浮点容差和产生差异的原因。

## 7. V3：求解器交叉验证

### 7.1 Mie 与独立参考

选择公开、受广泛使用的 Mie 实现或文献表格作为参考，至少覆盖：

- Rayleigh 区；
- Mie 共振区；
- 几何光学过渡区；
- 非吸收与吸收粒子；
- 水滴和典型气溶胶折射率。

比较 `Q_ext`、`Q_sca`、`Q_abs`、`Q_back`、`g` 和选定角度的散射矩阵元素。不得只对比总消光，因为后向散射更敏感。

### 7.2 T-matrix 球形极限

将轴比连续趋近 1，在相同波长、半径和折射率下比较 T-matrix 与 Mie：

- 截面；
- 角相函数；
- Mueller 元素；
- 后向散射；
- 球形退偏比。

该测试是当前项目中连接 Mie 与非球形链路最关键的交叉验证之一。

### 7.3 偏振传播极限

- 只允许一次散射时，与单次 Mueller 作用解析结果比较。
- 球形粒子、无多次散射时，粒子退偏应接近 0。
- 光学厚度趋近 0 时，多次散射修正应趋近 0。
- 关闭非球形效应时，结果应回到球形基线。
- 对非偏振入射和线偏振入射分别检查 Stokes 向量物理约束。

## 8. V4/V5：权威数据源与检索方案

### 8.1 ACTRIS/EARLINET

官方入口：ACTRIS Data Portal，`https://data.actris.eu/`。

建议检索词：

```text
ACTRIS EARLINET particle backscatter coefficient 532 nm
ACTRIS particle extinction coefficient 355 532 nm
ACTRIS particle linear depolarization ratio 532 nm
EARLINET aerosol lidar ratio dust smoke profile
```

目标变量：

- 粒子消光系数 `alpha_p(z)`；
- 粒子后向散射系数 `beta_p(z)`；
- 粒子线性退偏比；
- 激光雷达比；
- 气溶胶层顶/层底；
- 产品质量标志、时间和高度分辨率。

优先选择 532 nm，其次选择 355/1064 nm。候选联合站点可从 Leipzig、Granada、Potenza、Lille、Évora、Athens 等长期观测站开始检索，但必须以实际产品可用性为准。

对比方法：统一高度网格和时间平均窗口，比较廓线 Bias、RMSE、相关系数、AOD、层顶高度和退偏比。若下载的是反演量，需要记录其先验假设和误差；若下载的是原始信号，需要建立完整仪器前向算子。

### 8.2 AERONET Version 3

官方入口：`https://aeronet.gsfc.nasa.gov/`。

建议检索词：

```text
AERONET Version 3 Level 2 inversion download
AERONET size distribution complex refractive index SSA phase function
AERONET colocated EARLINET station dust event
```

下载：

- Direct Sun Level 2：光谱 AOD；
- Inversion Level 2：体积粒径谱、复折射率、SSA、相函数、非对称因子；
- 如 Level 2 不足，可将 Level 1.5 作为补充敏感性分析，但不能混淆质量等级。

关键转换：AERONET 常给出体积粒径分布 `dV/dlnr`，项目若需要数粒径分布，应转换为：

```text
dN/dlnr = [dV/dlnr] / [(4/3)*pi*r^3]
```

使用 AERONET 观测粒径谱和复折射率驱动项目，比较 AOD、SSA、相函数和 `g`。必须记录 AERONET 反演的典型波长；不能把 440/675/870/1020 nm 的复折射率无条件用于 1550 nm。

### 8.3 CALIPSO/CALIOP

官方入口：NASA Earthdata/ASDC 的 CALIPSO 数据目录。

建议检索词：

```text
CALIPSO CALIOP Level 1B attenuated backscatter 532 1064
CALIOP 532 perpendicular attenuated backscatter
CALIPSO Level 2 aerosol profile subtype depolarization
```

优先产品：

- Level 1B：532 nm 总衰减后向散射、532 nm 垂直偏振通道、1064 nm 衰减后向散射；
- Level 2：气溶胶层、气溶胶类型、消光、退偏和质量标志。

模型应生成与 L1 同定义的观测量：

```text
beta_att(lambda,z) = [beta_m(lambda,z)+beta_p(lambda,z)]
                     * exp(-2*integral(alpha_m+alpha_p+alpha_g, dz))
```

随后匹配垂直分辨率、空间平均、偏振通道、噪声和探测阈值。严禁将未衰减粒子 `beta_p` 直接与 CALIOP L1 总衰减后向散射对比。

### 8.4 NASA MPLNET

官方入口：`https://mplnet.gsfc.nasa.gov/`。

建议检索词：

```text
MPLNET Level 2 aerosol extinction backscatter 532 nm
MPLNET normalized relative backscatter AERONET site
```

适合获取地基 532 nm 连续时间序列。优先寻找与 AERONET 同站数据，用 AERONET 约束粒径谱和 AOD，用 MPLNET 验证距离廓线与时间演变。

### 8.5 DOE ARM

官方入口：ARM Data Discovery，`https://adc.arm.gov/discovery/`。

建议检索词或数据流关键词：

```text
ARM MPL aerosol backscatter
ARM ceilometer backscatter
ARM VDIS disdrometer drop size distribution
ARM sounding temperature pressure humidity
ARM visibility present weather fog
```

优先下载同一站点、同一时段的 MPL/ceilometer、雨滴谱、探空、地面气象和能见度产品。ARM 的优势是多仪器共址，适合构造完整前向输入和独立输出对比。

### 8.6 GPM Ground Validation 雨滴谱

建议检索：

```text
NASA GPM Ground Validation 2DVD drop size distribution
GPM GV Parsivel disdrometer rain event
MRR drop size distribution open data
```

目标变量：

- 逐时间段雨滴粒径谱 `N(D)`；
- 雨率；
- 粒径-落速二维分布；
- 数据质量标志；
- 温度、风速和同步雷达/激光雷达观测。

将实测 `N(D)` 直接输入模型：

```text
alpha_rain = integral[C_ext(D)*N(D), dD]
beta_rain  = integral[dC_sca(D,pi)/dOmega*N(D), dD]
```

将 Marshall-Palmer/Joss 经验谱作为基线而非真值。当前项目已知雨率相近时，实测后向散射可相差数倍，因此论文应将“实测粒径谱相对经验雨率谱的增益”作为重点结果。

### 8.7 雾观测：C-FOG、ParisFog 和共址观测

建议检索：

```text
C-FOG FM-120 droplet size distribution visibility dataset
ParisFog droplet size distribution visibility ceilometer
fog field campaign FM-100 FM-120 liquid water content MOR
```

目标变量：雾滴粒径谱、液态水含量、气象光学距离 MOR、温湿度、ceilometer/lidar 回波和雾层高度。

第一步比较 Mie 粒径谱积分消光与能见度：

```text
MOR approximately 3.912/alpha_ext
```

第二步再比较距离回波和有效探测距离。若只有能见度而无雾滴谱，只能验证总消光，不能独立验证粒径谱和后向散射。

### 8.8 ERA5、探空和分子廓线

数据入口：Copernicus Climate Data Store 的 ERA5，以及 NOAA IGRA 或观测站探空资料。

目标变量：气压、温度、相对湿度/比湿、位势高度。用途：

- 计算分子数密度和 Rayleigh 消光/后向散射；
- 构造真实分层大气；
- 计算湿度增长或折射率敏感性；
- 为 HITRAN 逐层气体吸收提供状态参数。

探空优先于再分析；没有探空时使用 ERA5，并明确其时空分辨率不是点测真值。

### 8.9 HITRAN/HAPI

官方入口：`https://hitran.org/`。

用途是计算 1550 nm 附近 H2O、CO2 等气体吸收。检索时应围绕实际激光中心波长和线宽，而不是只写“1550 nm”。需要记录：

- 精确中心波长/波数；
- 激光线宽；
- 温压廓线；
- 水汽廓线；
- 线型和截断方案。

论文中应区分粒子消光与气体吸收 `alpha_g`。

### 8.10 OPAC 和折射率数据

OPAC 是标准气溶胶光学模型/参考数据，不是真实观测数据库。应引用 Hess、Koepke 和 Schult（1998）的原始论文及对应数据版本，用于标准组分场景和 sanity check。

水和气溶胶复折射率应优先追溯原始实验资料。`refractiveindex.info` 可作为检索入口，但正式论文应引用 Hale-Querry、Segelstein 或对应材料的原始来源，并核对温度、波长和复折射率符号约定。

## 9. 数据筛选、配准与独立验证规则

### 9.1 事件筛选

每个事件建立一行元数据：

| 字段 | 内容 |
|---|---|
| `event_id` | 唯一事件编号 |
| 场景 | 雾/城市霾/沙尘/烟雾/降雨 |
| 时间 | UTC 起止时间 |
| 地点 | 站点、经纬度、海拔 |
| 输入数据 | 粒径谱、折射率、气象廓线等 |
| 验证数据 | lidar/ceilometer/CALIOP 观测量 |
| 产品版本 | Level、版本号、质量标志 |
| 配准窗口 | 时间、水平距离、高度范围 |
| 数据用途 | calibration/validation/test |
| 排除原因 | 云污染、完全衰减、质量标志等 |

### 9.2 建议配准初值

以下规则应在浏览结果之前冻结，必要调整时记录理由：

- 地基共址仪器：优先同站；非同站建议水平距离不超过 25 km。
- 地基时间窗口：优先 ±30 min，数据稀缺时可扩至 ±60 min。
- CALIPSO 过境：可从水平 50 km、时间 ±3 h 的候选窗口开始，再做敏感性分析。
- 高度网格：模型先按高分辨率计算，再卷积/重采样到观测分辨率。
- 云和完全衰减区：根据质量标志剔除，不能当作零气溶胶。

### 9.3 数据集划分

- Calibration：只用于确定无法从文献获得的少量系统参数。
- Validation：用于模型选择、误差分析和消融研究。
- Test：在方法和阈值冻结后仅运行一次，用于论文主结果。

若数据量过少，至少采用“一个事件调参、另一个事件验证”。所有拟合参数必须有物理范围，禁止逐事件任意缩放后再报告拟合精度。

## 10. 模型-观测前向对比方法

### 10.1 对比层次

优先比较最接近仪器原始测量的量：

1. L1 原始或定标衰减回波；
2. 由较少先验得到的光学量；
3. L2 消光/后向散射/分类产品；
4. 高度依赖先验的派生参数。

L1 对比更严格，但需要实现仪器响应；L2 对比更容易，但必须讨论反演先验造成的相关误差。

### 10.2 仪器前向算子

真实观测对比前至少处理：

- 波长和光谱响应；
- 发射能量、接收面积和系统常数；
- 几何重叠函数；
- 距离平方项；
- 时间/高度积分；
- 偏振串扰和通道增益；
- 探测器噪声、背景光、暗电流；
- 饱和、盲区和探测阈值。

若缺少系统常数，主对比可使用归一化廓线形状、衰减斜率、层高或 AOD，但必须明确不能验证绝对回波功率。

### 10.3 统计指标

至少报告：

```text
Bias, MAE, RMSE, NRMSE, Pearson r, median relative error
```

针对具体量增加：

- AOD 绝对差和相对差；
- 层顶/层底高度误差；
- 激光雷达比差异；
- 退偏比绝对误差；
- 有效探测距离误差；
- 观测落在模型预测区间内的覆盖率。

廓线数据存在强自相关，不能把每个高度 bin 当作独立样本夸大显著性。置信区间应按事件或时间块 bootstrap。

## 11. 不确定度与敏感性分析

### 11.1 输入不确定度

至少包括：

- 粒径谱测量误差和截断范围；
- 复折射率实部/虚部；
- 粒子形状、轴比和取向；
- 相对湿度及吸湿增长；
- 温压廓线；
- 仪器系统常数和重叠函数；
- 偏振串扰；
- 雨滴落速和非球形模型。

### 11.2 数值不确定度

- Mie 级数截断；
- T-matrix `nmax` 和收敛失败；
- 粒径、角度、距离离散；
- 插值和光谱外推；
- 随机采样误差；
- 浮点和跨平台差异。

### 11.3 模型结构不确定度

- 球形与非球形假设；
- 单次与多次散射；
- 均匀层与真实廓线；
- 经验谱与实测谱；
- 固定折射率与湿度依赖折射率；
- 仅粒子消光与粒子+气体吸收。

### 11.4 推荐方法

先做 Morris/局部灵敏度筛选，再对高敏感参数进行 Monte Carlo 或 Latin hypercube 传播。输出 Sobol 指数并非必需；对于会议论文，更重要的是给出可信的预测区间和主导误差来源。

## 13. 消融实验设计

至少设计以下成对对比：

1. Mie 球形 vs T-matrix 非球形。
2. 经验粒径谱 vs 实测粒径谱。
3. 单次散射 vs 多次散射/偏振传播。
4. 均匀大气 vs 真实分层大气。
5. 无噪声理想回波 vs 仪器噪声回波。
6. 固定折射率 vs 波长/湿度依赖折射率。
7. 无气体吸收 vs HITRAN 气体吸收，重点放在 1550 nm。

每个消融只改变一个因素，其他输入保持一致。结果应报告绝对变化、相对变化及其是否超过观测/数值不确定度。

| 缺少 1550 nm 廓线观测 | 无法直接证明应用波段精度 | 先在 532/1064 nm 建立可信度，1550 nm 做受约束预测并加入 HITRAN |
| 雨场缺少实测 `N(D)` | `alpha/beta` 不能同时匹配 | 使用 2DVD/Parsivel/MRR；经验谱只作 baseline |
| T-matrix 大尺寸/极端轴比不收敛 | 参数域受限 | 报告有效域，使用替代方法或限制结论范围 |
| 系统常数未知 | 不能比较绝对功率 | 比较定标后衰减后向散射、归一化形状、斜率、AOD和层高 |
| Level 2 产品依赖先验 | 验证不完全独立 | 尽可能增加 L1 前向观测对比并传播产品不确定度 |
| 参数过多导致过拟合 | 真实事件拟合好但无泛化 | 限制可调参数，校准/测试分离，参数范围来自文献 |
| 数据许可限制 | 无法随论文公开原始数据 | 发布查询脚本、manifest、DOI、文件哈希和派生统计 |
| 当前工作区存在未提交修改 | 结果版本可能混淆 | 正式计算前冻结分支/commit，并记录 dirty 状态 |

## 23. 预期论文结论的合格表达

最终结论应采用有边界的表述，例如：

> 本文模型在解析极限和独立求解器对比中满足预设数值容差；在选定公开气溶胶及降水事件中，能够再现主要消光、后向散射和偏振廓线特征。研究表明，粒径谱和非球形结构对后向散射的影响显著强于仅由能见度或雨率所表达的变化。由于公开 1550 nm 廓线观测有限，该波段结果被视为由可见/近红外验证和权威光学参数约束的预测，而非直接实验定标结果。

该表达只有在相应测试和数据对比完成后才能使用；具体误差数字必须来自冻结测试集。
