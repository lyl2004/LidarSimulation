# 简短讲解提纲

本文档用于对甲方进行简短讲述，可作为现场说明顺序。

## 1. 项目定位

本项目是一个 1D LiDAR 大气场景仿真评估工具。

核心目标是：输入激光雷达系统参数和雾、霾、雨等大气粒子场景参数，计算不同距离门下的回波功率、信噪比和退偏振特征，并通过界面展示图表、导出 CSV/PNG/SVG 结果。

## 2. 环境配置

项目依赖分为三类：

| 环境 | 作用 |
|---|---|
| `pixi gui` | 启动 NiceGUI 前端界面 |
| `pixi mie` | 执行 Python Mie、数值积分、绘图计算 |
| Julia | 执行霾粗模态非球形粒子的 T-matrix 计算 |

初始化命令：

```powershell
pixi run -e gui python -V
pixi run -e mie python -V
```

启动命令：

```powershell
.\run_ui.ps1
```

该脚本实际执行：

```powershell
pixi run -e gui python app/demo_ui.py
```

## 3. 源码框架

| 路径 | 作用 |
|---|---|
| `app/demo_ui.py` | 前端入口，负责参数编辑、历史结果切换、图表展示、结果导出 |
| `temp/lidar_1d/make_final_figures.py` | 计算包装器，负责拼接命令并调用核心脚本 |
| `temp/lidar_1d/lidar_1d_simulation.py` | 核心计算脚本，负责光学散射、雷达方程、噪声/SNR、退偏振、结果生成 |
| `src/mie_core.py` | Mie 偏振散射公共模块 |
| `src/cache_keys.py` | 生成缓存 key，判断参数是否命中已有结果 |
| `src/cache_runtime.py` | 管理默认结果、历史结果、活动结果和缓存索引 |
| `src/path_resolver.py` | 统一解析 Python、Julia 和安装目录路径 |

## 4. 核心工作流

1. 用户打开 UI。
2. UI 默认加载 `default_result/` 或最近一次历史结果。
3. 用户在左侧修改仪器、大气、雾、霾、雨、噪声参数。
4. 点击重算后，前端根据当前参数计算缓存身份。
5. 如果命中完整历史结果，则直接切换展示。
6. 如果没有完整命中，则写入 `param_overrides.json`。
7. UI 调用 `make_final_figures.py`。
8. `make_final_figures.py` 调用 `lidar_1d_simulation.py`。
9. 核心脚本计算光学参数、回波功率、SNR 和退偏振曲线。
10. 结果写入 `outputs_high_precision_latest/local/`。
11. UI 将本次结果归档到 `run_history/`，并刷新图表。

## 5. 输入重点

输入主要分为六组：

| 参数组 | 内容 |
|---|---|
| 仪器参数 | 波长、峰值功率、脉宽、接收半径、光学效率 |
| 接收端噪声参数 | 量子效率、背景光、暗电流、读出噪声、平均脉冲数 |
| 大气分子参数 | 分子消光、分子后向散射、分子退偏振比 |
| 雾场景参数 | 辐射雾、平流雾的粒径谱和折射率 |
| 霾场景参数 | 四类霾的 fine/coarse 模态粒径谱和折射率 |
| 雨场景参数 | 小雨、中雨、大雨的降雨率 |

## 6. 计算流程重点

核心雷达方程：

```text
P(R) = C * O(R) * beta * exp(-2 * alpha * R) / R^2
```

其中：

| 符号 | 含义 |
|---|---|
| `R` | 距离 |
| `C` | 系统常数 |
| `O(R)` | 几何重叠因子，当前为理想值 1 |
| `alpha` | 总消光系数 |
| `beta` | 总后向散射系数 |

光学计算分三类：

| 场景 | 方法 |
|---|---|
| 雾 | Mie 散射 |
| 霾 | 细模态 Mie，粗模态可用 Julia T-matrix |
| 雨 | Marshall-Palmer 雨滴谱 + Mie 散射 |

随后计算：

| 结果 | 说明 |
|---|---|
| 回波功率曲线 | 不同距离上的 `P(R)` |
| 噪声底 | 接收端噪声形成的 RMS 功率噪声 |
| 信噪比 | `SNR_linear` 与 `SNR_dB` |
| 退偏振比 | 主要用于霾场景偏振特征分析 |

## 7. 输出结果重点

默认结果目录：

```text
temp/lidar_1d/default_result/
```

当前重算结果目录：

```text
temp/lidar_1d/outputs_high_precision_latest/local/
```

历史结果目录：

```text
temp/lidar_1d/run_history/
```

主要输出：

| 输出 | 内容 |
|---|---|
| `summary.json` | 全局参数、场景光学参数、SNR 摘要、退偏振摘要、缓存身份 |
| `params.json` | 本次运行使用的参数快照 |
| `data/*.csv` | 曲线数据，包括距离、功率、噪声、SNR、退偏振 |
| `figures/*.png` | PNG 图像 |
| `figures/*.svg` | SVG 矢量图 |

## 8. 可重点强调

这个项目不是单纯画图工具，而是一个“参数输入、物理计算、缓存复用、结果归档、图表展示”的完整仿真链路。

它可以快速比较不同天气和气溶胶场景下的：

| 对比项 | 说明 |
|---|---|
| 回波强弱 | 不同天气下雷达接收功率变化 |
| 探测距离 | SNR 达标距离 |
| 偏振差异 | 霾场景退偏振特征 |
| 参数敏感性 | 修改仪器或大气参数后快速重算对比 |

结果以 JSON、CSV、PNG、SVG 形式保留，便于验算、汇报和复现。
