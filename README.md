# 1D 激光雷达散射仿真（用户手册）

本软件用于 **1550 nm 单波长脉冲激光雷达** 在雾、霾、雨场景下的回波功率与退偏比仿真。

---

## 1. 软件功能

### 1.1 场景覆盖

软件内置 9 个典型场景：

- 雾：辐射雾、平流雾
- 霾：城市/工业型、乡村/大陆背景型、沙尘型、海洋性
- 雨：小雨（1 mm/h）、中雨（5 mm/h）、大雨（12 mm/h）

### 1.2 输出内容

每次计算会生成：

- 图像：PNG、SVG
- 数据：CSV（每条曲线单独导出）
- 汇总：`summary.json`（关键光学参数）

### 1.3 交互能力

- 左侧参数面板可编辑仪器参数与场景参数
- 右侧分组图表查看功率曲线与退偏曲线
- 支持历史结果切换
- 支持“恢复默认”快速回到内置默认结果
- 支持单文件导出和整包导出

### 1.4 缓存与加速

软件使用分级缓存：

- 光学散射缓存（Mie / T-matrix）
- 默认缓存种子（fast / medium / high）
- 回波结果重建（图像与 CSV）

因此在缓存命中时，可跳过部分或全部耗时的散射重算，仅重建最终曲线或直接切换到已有结果，显著缩短等待时间。

默认结果与默认缓存的设计固定如下：

- 软件会预计算 `fast / medium / high` 三档默认参数缓存。
- 只有 `high` 会生成完整、可直接展示的默认结果集，目录为 `temp/lidar_1d/default_result`。
- `fast / medium / high` 三档的默认缓存工件统一保存在 `temp/lidar_1d/cache_store/seeds`。
- `fast / medium` 默认结果仅用于首次命中加速，不在界面中单独显示为历史结果。
- 安装包会同时附带：
  - `default_result`：默认高精度展示结果
  - `cache_store/seeds` 与 `cache_store/index`：默认缓存种子与索引

## 2. 软件用法

### 2.1 启动

双击 `LidarSim.exe`（或安装后从桌面快捷方式启动）。

首次启动会加载内置默认结果集。

### 2.2 基本流程

1. 在左侧修改参数（可只改一部分）
2. 点击“写入并重算”
3. 在“查看日志”中观察计算进度
4. 在右侧查看图像与曲线
5. 使用下载按钮导出 PNG/SVG/CSV 或整包结果

### 2.3 历史与默认

- 每次成功重算会生成一条历史记录
- 可在“历史记录”中切换不同结果
- 点击“恢复默认”会切换到内置默认结果（只读）

### 2.4 精度模式（建议）

- **快速**：用于参数试探和趋势判断
- **中速**：用于常规分析
- **高精度**：用于最终报告与数据留存

若结果将用于正式对比或归档，建议最终以高精度再计算一次。

## 3. 结果置信边界（重要）

以下内容用于说明“结果可信到什么程度、在哪些条件下需要谨慎”。

### 3.1 物理模型边界

软件基于 1D 激光雷达方程与给定粒径分布模型，适用于：

- 单站、单波长（1550 nm）
- 距离向平均行为分析
- 典型雾霾雨场景的相对变化比较

不适用于：

- 多次散射主导且强非均匀路径的精细反演
- 非内置类型介质的严格定量反演（除非完成参数标定）
- 需要 3D 空间结构求解的场景

### 3.2 参数依赖边界

输出对以下输入敏感：

- 粒径分布参数（数量浓度、几何均值半径、几何标准差）
- 折射率设定
- 仪器常数（由发射功率、脉宽、接收口径、效率共同决定）

若输入参数来自经验估计而非实测标定，结果应作为“趋势参考”，不应直接当作绝对测量值。

### 3.3 精度与速度边界

- 快速模式优先速度，误差通常高于中速/高精度
- 高精度模式耗时明显更长，但数值稳定性更好
- 首次运行某组新参数时可能较慢（需建立缓存）

### 3.4 缓存相关边界

- 界面展示的是“当前参数组合在缓存池中的执行计划”，而不是旧版的“项目级是否重算”状态
- 缓存命中时速度快，不代表模型改变；只是跳过了重复计算
- 修改关键散射参数后，缓存会自动失效并重算
- 仅修改仪器参数时，系统通常只重建功率、CSV 与图像，而不重算散射
- 若你切换到全新参数组合，出现长时间计算属于正常行为

## 4. 日志与故障判断

### 4.1 日志入口

点击界面“查看日志”可看到完整计算输出。

### 4.2 常见正常现象

- 日志出现 `T-matrix` 且耗时较长：正常（霾场景通常最耗时）
- 首次新参数运行明显慢、后续变快：正常（缓存建立后命中）

### 4.3 需要关注的异常

- 日志出现 `failed` / `error` / `RuntimeError`
- 结果目录无新图像或无 CSV
- 重算结束后图表未刷新

出现异常时，优先保留日志并重试一次同参数运行，以区分“首次初始化慢”与“真实错误”。

---

## 5. 使用建议

- 做参数探索时先用快速模式，确定区间后再用高精度
- 仅改仪器参数后若耗时仍异常长，检查日志是否出现“全量重算”
- 用于报告时保留对应 CSV 与日志，便于追溯参数与计算条件
